## 当前阶段：真实端到端试跑

Release 1 的硬化工作（R1-S3L 之后的 backfill、发布审计等）暂停。R1-S0～S3L 已完成，记录见 [history.md](./history.md)。完整链路还没有人用真实模型从头跑通过，下一步由 Owner 做一次试跑，再用试跑结果决定优先级。

试跑路径：

1. **开书**：从一句想法开始，走公共入口进入自动导演。
2. **自动导演**：书级规划、世界、角色、卷章规划，一直到可以写章。
3. **连续写章**：至少连续产出若干章，观察质量债是否只作警告、不误停整书。
4. **暂停/恢复**：中途关闭或暂停，再从来源页恢复，确认不重复生成、不丢已保存正文。
5. **导出**：从来源页导出整本 TXT，在系统编辑器里核对首尾章。

试跑时请记录：模型与参数、每一步耗时、需要人工决定的次数、报错与卡住的位置、恢复后是否重复调用。只用试跑专用作品，不在已有作品库上做破坏性操作。

## 试跑后的处理

- 每个问题按 [AGENTS-fork](./AGENTS-fork.md) 分级：普通缺陷和体验问题走“实现 → 一次评审 → 合并”；涉及数据/迁移、发布/打包、运行时或 Prompt 合同的走完整流程。
- 试跑能顺带验收 [backlog 第 1 组](./backlog.md#1-试跑中顺带验收已合入-beta)的 WGR 项和 R1-03 的 TXT 打开证据，结果回写 backlog。
- 试跑后按问题严重度重排 backlog，再决定是否恢复 S3-02b3c2 起的 backfill 链或其他候选。

### 试跑反馈：短篇创作方向选择

- **用户价值**：初次生成时能比较更多符合原意的题材方向；不满意时只重做单个方向，不丢失其余候选。
- **范围**：短篇入口默认 4 个方向，可选 2/4/6；单项选填反馈、局部加载与失败保留；确认时采用所选方向的创作底座。
- **非范围**：长篇候选数量、短篇正文生产、已有作品的修改流程、模型供应商设置。
- **依赖**：创作意图 Prompt Schema、共享类型、创作工作室接口和页面；不做数据库迁移。
- **验收**：数量和差异符合选择；单项重做保留其他候选并可刷新恢复；失败不丢原项；重做中的旧项不能确认；所选题材进入短篇生产。
- **最窄验证**：共享/服务端/客户端类型检查，创作工作室定向合同测试，独立 QA 检查失败、重试、并发与恢复；界面交互由 Owner 验收。
- **文件边界**：`shared/types/creationStudio.ts`、创作意图 Prompt、创作工作室服务/API/页面及对应定向测试；稳定规则更新到创作工作室 Wiki。

代码已合入本地 `main` 与 `beta`，独立 QA 与定向检查通过；界面交互留给 Owner 验收。
