# 独立发行版 Backlog

所有未完成事项，一行一项。点数为相对复杂度；“未估”表示尚未估点。状态：`待验收`＝代码已在 beta，等待用户真实验收；`Refinement`＝合同未冻结；`Not Ready`＝依赖或合同未满足；`Partial`＝已有部分能力（R1-00 对账口径）；`Spike`＝只产出决策与证据。

优先级由[试跑](./board.md)结果决定。本表不是承诺顺序；按 [AGENTS-fork](./AGENTS-fork.md) 的分级流程处理：试跑问题和普通修复不需要写 Story 合同。
