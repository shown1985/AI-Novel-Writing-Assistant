# 世界样本开书入口验收范围

## 用户价值

用户选中世界样本后，可直接进入开书页，让 AI 按该世界提供开局灵感，并沿用自动导演完成小说准备。

## 范围与边界

- 样本列表提供“基于这个世界创作”，向现有自动导演入口传递 `worldId`。
- 起始页展示所选世界及生成灵感入口；沿用现有灵感、故事星图、方向候选与确认链路。
- 开局灵感、星图和方向候选读取样本内容，而非只传名称或 ID；只读样本，不在浏览和生成方向时创建小说副本。
- 沿用已有确认后的本书世界复制流程；不修改数据库、任务状态契约、公共输出 schema 或添加新生成流水线。
- 不增加短篇入口、样本管理能力、同步策略或自动正文生成策略。

## 依赖与文件边界

- 前端 owner：世界列表、自动导演创建页、起始页和开书草稿模块及针对性测试。
- 后端 owner：WorldService 的只读规划参考接口、导演灵感上下文与候选阶段、已注册相关 Prompt 及针对性测试。
- 主线程负责分支、整合评审、发布说明、Wiki 与阶段提交；独立 QA 审查跨入口恢复和失败行为。
- 使用已有 `worldId` 请求字段、WorldService、结构解析/压缩、已注册结构化 Prompt 和确认复制链路。

## 验收条件

1. 从样本 A/B 进入后自动选择正确世界；普通开书和不同样本的草稿彼此隔离，普通旧草稿仍能恢复。
2. 刷新恢复用户草稿；已创建任务的保存状态优先于 URL，用户调整世界后不被原始 URL 强制覆盖。
3. 无需先写故事即可点击 AI 灵感；生成采用实际样本内容，选择灵感后可以继续现有方向生成和确认。
4. 未选择世界沿用原行为；失效样本显示明确错误并可清除或返回选择，不能静默生成其他世界。
5. 重试与单候选调整保留世界约束；生成过程不写样本、不提前导入本书世界。

## 最窄验证

- 前端类型检查、草稿隔离与来源优先级测试。
- 后端类型检查/编译及只读样本上下文、生成/重试传递、失效样本测试，使用替身，不访问用户数据库或模型。
- 独立代码 QA；页面操作与生成效果由用户验收。

## 交付验证

- 前端最终修改后的类型检查通过；草稿兼容、隔离与优先级测试 6/6 通过。
- 服务端最终源码构建通过；定向测试 65 通过、2 跳过、0 失败。后续只有测试补强，沿用这次构建。
- 独立 QA 重跑只读参考模拟测试 4/4，通过超长内容裁剪、传统字段、空选择免查询、冻结重试，以及七个失效样本入口在模型和任务写入前失败的验证。
- 评审补齐旧来源异步回调的导航存活保护，并保留已创建小说的进度、恢复和生产模式交接。
- UI 状态：留给用户验收。未运行浏览器验收或真实模型生成，未修改用户数据库。

## 输入与结果体验修复范围

用户反馈：修改起始输入后按钮仍可能展开旧想法；结果位于首屏下方，需要额外滚动才能发现。本阶段为 3 点，修复输入约束和选择体验。

- 点击生成使用当前输入与所选世界，旧输入的缓存结果及迟到响应不得冒充本轮结果。
- 非空输入中的具体人物、目标、事件与限制是五条开局共同的创作要求；由已注册的灵感 Prompt 判断并保留。空输入继续基于世界或基础偏好发散。
- 沿用项目弹窗与灵感组件，在弹窗中展示本轮输入、世界、生成状态、完整想法、重试和使用操作。关闭不改输入，明确使用后才替换。
- 边界：仅灵感入口及其请求状态、提示词与展示；不改故事星图生成、候选流水线、任务恢复、数据库或公共输出 schema。
- 文件 owner：前端负责 StageIdea、控制器、既有灵感组件和专属灵感目录；后端负责灵感 Prompt、对应注册版本与已有聚焦测试。主线程维护文档并由独立 QA 检查输入传递、迟到响应、错误重试、关闭与使用。
- 验证：前端类型检查和输入来源状态测试；服务端编译与模拟调用验证 currentIdea 及世界上下文在首轮/重试中保留、Prompt 对应版本和渲染约束。页面观感与真实 AI 输出留给用户验收。

### 本阶段验证结果

- 前端类型检查通过；输入变化与迟到响应测试 2/2 通过。最终仅在按钮条件中加入已有布尔状态，没有改变类型结构，复用这次类型检查。
- 服务端最终灵感 Prompt 与对应注册版本构建通过，聚焦测试 14/14 通过。
- 独立 QA 重跑上述定向测试，并用替身分别验证非空/空输入与所选世界在首轮及结构失败后的重试中完整传递，每次生成只读一次世界参考。没有真实模型或用户数据库调用。
- 评审消除固定灵感角度与用户指定人物、系统等核心要求之间的提示词冲突；灵感请求沿用已有请求钩子，输入变化同步使旧请求失效。
- UI 状态：留给用户验收。当前功能分支供本机服务试跑，页面观感与真实模型对要求的保留效果尚未验收。
