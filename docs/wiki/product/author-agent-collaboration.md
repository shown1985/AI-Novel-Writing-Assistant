# 作者与 Agent 的协作合同

## 背景

作者表达的需求常是“这章太平淡”“主角不像我想要的人”“帮我继续这一段故事”。按后台模块划分操作，要求新手理解世界、角色、卷战略、章节审校之间的调度关系，会增加完成长篇的负担。

交互重设计需要兼顾三种需求：新手尽快读到成果，连载作者保持连续产出，重视个人表达的作者保留留白与主导权。三位独立作者视角代理明确同意这一方向；代理评审不等于真实访谈或产品验收。

本文记录设计决策和实现约束。新版协作入口、委托权限、预算与恢复能力须按对应Story实现，不能因本文存在就声称功能可用。

## 决策

创作以具体作品的持续推进为中心，资产提供可复用起点与积累；同一作品保持稳定的阅读/编辑现场。Agent理解要求并调用已治理能力，用户查看实际成果、判断关键方向、授权范围。

默认正文优先，资料与协作区域按需打开。对话用于表达要求，编辑器用于读写长稿，提案差异用于审阅，图谱用于理解关系；不强迫所有工作进入聊天或固定三栏。

## 当前实现边界与后续要求

- 自动导演、章节生产、Prompt Registry、状态回灌继续承担执行；新交互必须复用它们的命令与事实状态。
- Creative Hub保留查询导航职责。执行在小说、章节、世界、角色等正式来源页完成；运行记录只读。
- 简易模式当前用户写权限受服务器限制，转专业不可逆。后续开放协作修改要设计系统委托与权限合同，不能只在前端加按钮。
- 作者保护、角色对话确认、思路线非正史、quality-first人工暂停等现有合同继续生效。
- 缺省配置、能力状态读取、选择来源与任务预算属于不同能力。maxTokens限制单次请求，不代表整任务预算。

## 创作与资产

外部样本、基础角色、写法、题材与参考资料用于起点、方法和素材。本书实例承接当前小说的事实、计划、角色处境与使用范围。

导入和适配必须保留来源与版本；本书演进不自动覆盖公共样本，样本更新不自动改写本书或发布稿。现有本书世界生成/手动创建会生成关联样本；首次创建与后续push/pull同步是两种动作，不能混为自动持续回写。

世界进入生成链通过WorldContextGateway。图谱、UI摘要和未经确认的推演不能成为新的权威事实源。

## 作者决定与委托

一次委托说明目标、资源/章节范围、允许修改、必须保留、完成标准及执行边界。普通内部步骤不逐项询问，重要方向改变或保护冲突回来源现场说明。

默认有推荐动作，允许自由输入、拒绝、部分采用和请求其他方案。创作偏好不能被压成AI预设选项的上限。

事实、人物认知、计划、AI推断、试演分别记录。作者标注的刻意留白、误解和未决定真相必须进入对应生成/审校上下文，避免AI为追求一致性反复抹平悬念。

## 质量、结果与恢复

问题应说明证据、故事影响与可执行提案。completion-first普通局部质量债可继续；明确重规划、不可用内容、安全问题及quality-first人工暂停依既有策略处理。

实际内容改动、作者处理声明与验证结果不同。已解决需关联评估版本与证据；重检保留身份和历史，AI检查失败不伪装通过。

修改交付展示差异、保留内容、后续影响与恢复范围。版本过期不写，采用幂等。采用成功后复核失败，应显示内容已保存、待复核，恢复不重复采用。

现有世界快照不具备跨本书与后文的全局撤回。功能只承诺已经实现的版本与依赖恢复范围；已发布或受保护内容不得自动覆盖。

## AI 配置与能力状态

查看设置读取最近诊断，不发模型或embedding请求。显式检测产生诊断和兼容建议，应用设置另走正式保存命令。

未检测、失效缓存、诊断失败、读取失败分别表达。诊断按配置指纹隔离，结果脱敏；历史模型选择由运行记录保存，不按当前默认重算。

完整的基础运行配置允许开始创作，连接未检测不能成为新增付费前置审批。检测建议的采用须在服务端校验配置仍有效，不以页面提醒代替并发写入保护。

模型策略和委托预算在后续合同中明确生效层级：系统默认、本书偏好、本次委托。恢复保持同一任务快照，预算包含重试、修复与备用调用，不仅统计主笔正文。

## 示例与失败模式

作者说“主角太被动，别突然变强”，Agent定位场景，提出依靠信息交换主动推进的改稿，保护战力和既定结局；采用后检查相关计划，并展示修改结果。

作者说“人物认为神迹不可伪造，但世界真相还没决定”，系统分别记录人物认知和待定真相，继续守已确认规则，不将认知误认当作必须消除的世界矛盾。

常见失败：

- 把字段表单换成几十条追问，仍要求新手自行调度。
- 打开状态页隐式调用付费模型，探测顺便更改正式配置。
- 简易页显示可改稿，但服务器权限拒绝或绕过旧门禁。
- UI标已解决，但手册、生成上下文、问题历史与评估版本未同步。
- 把角色对话、思路线或试演提升为世界事实。
- 仅恢复文本，却声称事实、计划和后文依赖已全部撤回。
