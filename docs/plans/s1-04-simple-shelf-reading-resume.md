# S1-04：简易书架阅读现场恢复

## Story 结论

- Release / Sprint：Release 1 / R1-S1。
- Story：S1-04 简易书架阅读现场恢复（3 点）。
- 用户价值：作者刷新、前进后退或重新进入作品后，可以继续阅读同一章并回到接近原来的阅读位置。
- 当前状态：`User Acceptance`。代码级验收已通过；仍需用户按本页清单完成真实浏览器交互验收，不能提前标记 `Done`。

## 已实现边界

- `chapterId` 查询参数是当前选章的事实源；点击章节会更新 URL，浏览器前进、后退和合法深链接均按 URL 恢复。
- 普通作品入口没有 `chapterId` 时，按作品恢复最近可读章节并以 replace 规范化 URL；显式合法深链接优先于本地偏好。
- 无效、不存在或没有正文的章节使用既有“最后一个可读章节”策略；没有可读正文时不虚构选择。
- 最近章节按作品隔离，阅读位置按作品与章节双重隔离；旧作品的响应不会成为新作品的展示数据。
- 正文未变化时恢复精确滚动位置；正文版本变化时按原阅读进度比例映射，并限制在当前可滚动范围内。
- 浏览器存储不可用、已满或内容损坏时退化为正常阅读，不阻断正文展示。
- 简易模式仍为只读阅读入口；本 Story 不增加正文编辑能力，也不改变后台生成、暂停或资料债规则。

## 用户验收清单

1. 打开有多章正文的简易书架，选择中间章节并滚动到正文中部；刷新后仍停留在同章并回到接近原位置。
2. 离开作品后从普通入口重新进入；应恢复刚才章节，并在 URL 中看到对应 `chapterId`。
3. 切换到另一本作品；不能沿用上一部作品的章节或滚动位置。
4. 使用浏览器前进、后退切换两个章节；标题与正文应和 URL 中的章节一致。
5. 在作品继续运行或暂停时阅读已经保存的章节；运行状态不能遮挡可读正文。
