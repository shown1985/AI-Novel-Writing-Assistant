# S1-02b：设置与知识库诊断状态消费完成证据

## Story 结果

- Release：Release 1 单机成书版。
- Sprint：R1-S2B。
- 点数：3。
- 状态：Done。
- 用户价值：作者打开设置、模型路由或知识库时只读取最近一次诊断；只有明确点击检测才会连接模型、embedding 或向量库。未知、配置已变、检测失败、读取失败和检测中均有独立解释。

## 交付范围

- 设置概览和模型路由页改用只读 readiness GET；页面进入、刷新、重新聚焦与活动租约轮询不复用检测命令。
- 模型路由和知识库的显式检测使用独立 POST，并在同一请求未结束时合并重复触发。
- 检测完成只失效当前 GET；配置保存后重置 readiness，迟到的旧 POST 结果不能直接写进当前指纹缓存。
- 客户端统一消费 `not_checked / healthy / failed / stale / pending / loading / error`，知识库不再读取旧 `ok` 布尔值。
- 基础模型配置有效时，仅最近一次明确的路由检测失败会阻止创建；未检测、过期、读取失败和检测中保持建议态。
- pending 只在服务端租约有效期内每 1.5 秒读取一次；租约结束后停止轮询。
