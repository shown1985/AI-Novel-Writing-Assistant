# 诊断状态展示模块

## 职责

本模块把服务端 readiness 报告转换为设置页与知识库页共用的展示状态，并提供活动检测的有限轮询、显式命令防重和配置变化后的缓存失效策略。页面只从 `index.ts` 使用这些规则，避免分别解释未知、过期、失败、读取错误和检测中状态。

## 边界

- 只处理纯展示判断、状态文案、目标摘要和 pending 租约时间。
- 不自行选择或发起 API、模型、embedding 或向量库请求；页面注入的 GET 与显式 POST 必须走各自策略。
- 不修改模型路由、知识库设置或任何持久化配置。
- 显式检测命令仍由来源页面的 mutation 触发；本模块不能把查询变成检测。
- 配置写入成功后清除旧 readiness 缓存；检测完成只失效查询并重新 GET，不能把迟到 POST 响应直接写入缓存。
- 建议应用不属于本模块，后续实现必须继续经过服务端 CAS 与幂等合同。
